Context Atlas privacy policy

Last updated: 2026-09-21

Contact: billy.suharno@gmail.com

Context Atlas does not use analytics, sell data, or load remote executable code.

Page text and search modes

The extension reads visible page passages after the user opens it. Local keeps page text in the browser. Cloud sends the question and bounded page passages only after a user-initiated search.

Storage and credentials

The optional Cloud access key and selected search mode are stored locally in Chrome extension storage. The key is not shown after saving, is not sent to page scripts or Local, and can be removed with Clear saved key or by uninstalling the extension.

Current page companion

The separate localhost page requests the latest bounded source through an exact-origin extension bridge. It does not replace the panel on the current webpage or require manual document fields.

Model data

Local downloads pinned model data from the manifest's declared hosts. Chrome asks for access to those hosts when Local search starts for the first time, not during installation. WebGPU is preferred and bundled WASM CPU is the fallback. Page text is not sent to the model host.

Third-party services

If you choose Cloud, Chrome asks for access to the Cloud service. The extension then sends the search question and bounded visible page passages to the configured Cloud search service only after you start the search. The locally stored Cloud access key is used for that request and is not sent to page scripts or Local. That service's own privacy policy applies to the request. Local search does not send page text to that service.

Retention and deletion

The extension does not keep an account or analytics history. The current page snapshot lasts only for the active browser session. The selected search mode and optional Cloud access key remain in local extension storage until changed, cleared in Settings, or removed by uninstalling the extension. Cloud retention is controlled by the configured Cloud service.

Changes and contact

This policy will be updated if Context Atlas changes what it stores or sends. The date above identifies the latest version. For privacy questions, contact billy.suharno@gmail.com.
