<Warning>
The `n8n-nodes-openbrowser` community node is not published. There is no installable npm package or n8n community node yet. Do not run `npm install n8n-nodes-openbrowser`; it returns 404.
</Warning>

## Current options

You can still drive OpenBrowser from n8n with an **Execute Command** node:

```bash
openbrowser-ai -c "await navigate('https://example.com'); print(await evaluate('document.title'))"
```

Or call the MCP server from an MCP-capable node:

```bash
uvx openbrowser-ai --mcp
```

For the CLI daemon workflow, see [CLI Daemon](/customize/integrations/cli-daemon). For the MCP tool catalog, see [Browser Automation MCP](/customize/integrations/mcp-server).

## Status

The community node remains a planned integration. This page will be updated when a published package exists.
