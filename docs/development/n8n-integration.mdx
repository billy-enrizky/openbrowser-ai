## 1. Current options

You can still drive OpenBrowser from n8n with an **Execute Command** node:

```bash
openbrowser-ai -c "await navigate('https://example.com'); print(await evaluate('document.title'))"
```

For static pages, use OpenBrowser no-browser mode:

```bash
openbrowser-ai scrape https://example.com --no-browser --format markdown
```

`--no-browser` starts no Chrome, Blink, or V8 process and never falls back to a browser. It cannot run JavaScript, take screenshots, or use browser cookies. Use the default `auto` engine when a page needs JavaScript.

Or call the MCP server from an MCP-capable node:

```bash
uvx openbrowser-ai --mcp
```

The lean stdio transport is the default. Set `OPENBROWSER_MCP_TRANSPORT=sdk` to use the MCP SDK transport. Invalid values exit with code 2. Modern `2026-07-28` clients see seven tools: `create_context`, `execute_code`, `get_status`, `reset_browser`, `close_context`, `web_search`, and `scrape_web`. The legacy handshakes `2024-11-05`, `2025-03-26`, `2025-06-18`, and `2025-11-25` see four tools: `execute_code`, `get_status`, `reset_browser`, and `web_search`.

For the CLI daemon workflow, see [CLI Daemon](/customize/integrations/cli-daemon). For the MCP tool catalog, see [Browser Automation MCP](/customize/integrations/mcp-server).
