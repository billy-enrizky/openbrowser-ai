## 1. Overview

OpenLIT is an open-source OpenTelemetry-native observability tool. OpenBrowser does not ship a native OpenLIT integration and does not create spans for individual browser actions. OpenLIT can instrument the LLM SDK calls that run in the same process, such as OpenAI or Anthropic chat calls.

Read more in the [OpenLIT docs](https://docs.openlit.io).

## 2. Setup

Install OpenLIT alongside the OpenBrowser package:

```bash
pip install openlit openbrowser-ai
```

## 3. Usage

Initialize OpenLIT before creating the agent:

```python
import asyncio

import openlit
from openbrowser import Agent, Browser, ChatOpenAI

openlit.init()


async def main():
    browser = Browser()
    llm = ChatOpenAI(model="gpt-4.1-mini")
    agent = Agent(
        task="Search for the latest AI news",
        browser=browser,
        llm=llm,
    )
    await agent.run()


if __name__ == "__main__":
    asyncio.run(main())
```

OpenLIT records the LLM SDK calls it supports. It does not record CDP commands, DOM actions, navigation phases, or browser health. Use `agent.status` and `session.lifecycle_snapshot()` for browser-side state.
