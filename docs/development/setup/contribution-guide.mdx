## 1. Mission

- Make developers happy
- Do more clicks than human
- Tell your computer what to do, and it gets it done.
-  Make agents faster and more reliable.


## 2. What to work on?

- This space is moving fast. We have 10 ideas daily. Let's exchange some.
- Browse our [GitHub Issues](https://github.com/billy-enrizky/openbrowser-ai/issues)
- Check out our most active issues on [Discord](https://discord.gg/YRXzbJjq9K) 
- Get inspiration in [`#showcase-your-work`](https://discord.com/channels/1458995201564737670/1459104487074431080) channel


## 3. What makes a great PR?

1. Why do we need this PR?
2. Include a demo screenshot/gif 
3. Make sure the PR passes all CI tests
4. Keep your PR focused on a single feature 


## 4. How?
1. Follow [Local Setup](/development/setup/local-setup) and run `bash scripts/ci/run_static.sh .`
2. Fork the repository
3. Create a new branch for your feature
4. Submit a PR

We are overwhelmed with Issues. Feel free to bump your issues/PRs with comments periodically if you need faster feedback.
