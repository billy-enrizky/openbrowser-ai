## 1. Clone and install

```bash
git clone https://github.com/billy-enrizky/openbrowser-ai
cd openbrowser-ai
uv sync --all-extras --dev
```

Python 3.12 or newer is required. `uv sync --all-extras --dev` installs the base package, optional providers, the interactive CLI, and the test and static-check tools.

## 2. Configure

Create `.env` at the repository root:

```bash
touch .env
```

Add one provider key for Agent or CodeAgent work:

```bash
GOOGLE_API_KEY=...
# or OPENAI_API_KEY=...
# or ANTHROPIC_API_KEY=...
```

MCP and `openbrowser-ai -c` do not need an LLM key. Optional settings:

```bash
OPENBROWSER_LOGGING_LEVEL=debug
OPENBROWSER_HEADLESS=true
OPENBROWSER_ALLOWED_DOMAINS=example.com,*.example.com
```

Run `uv run openbrowser-ai config status` to inspect the selected config path and state.

## 3. Verify without a browser

Search and HTTP-only scraping work before Chromium is installed. Neither command starts a browser:

```bash
uv run openbrowser-ai search "OpenBrowser MCP docs" --max-results 5
uv run openbrowser-ai scrape https://example.com --engine http --format text
uv run openbrowser-ai scrape https://a.example https://b.example --engine http --jsonl --concurrency 8
```

Search snippets are not evidence. Scrape and read the source page before you cite it.

## 4. Install Chromium

```bash
uv run openbrowser-ai install
```

## 5. Verify a browser session

```bash
uv run openbrowser-ai --version
uv run openbrowser-ai -c "await navigate('https://example.com'); print(await evaluate('document.title'))"
```

A warm `-c` call uses a standard-library thin client and does not import the full CLI or agent stack. A cold call falls back to the full client and starts the daemon.

The second command starts the CLI daemon, opens a real browser, prints the page title, and leaves the daemon running for later calls. Stop it when finished:

```bash
uv run openbrowser-ai daemon stop
```

Poll `uv run openbrowser-ai daemon status` until it reports `daemon_not_running`, or run `daemon force-stop` to wait and verify cleanup.

## 6. Tests and static checks

```bash
# Full non-integration suite
uv run pytest -q -m "not integration"

# Focused MCP protocol and lifecycle tests
uv run pytest tests/test_mcp_protocol.py tests/test_mcp_lifecycle.py -q

# Ruff, Pyright, format, backend compile, and backend smoke checks
bash scripts/ci/run_static.sh .
```

Integration tests that need a real browser are marked `integration`:

```bash
uv run pytest -q -m integration
```

## 7. Coding agent skills

Install the OpenBrowser skill pack with skills.sh:

```bash
npx skills add billy-enrizky/openbrowser-ai
```

Install only the first-time setup skill:

```bash
npx skills add billy-enrizky/openbrowser-ai --skill setup -a codex
```

Claude Code can also use the plugin marketplace:

```bash
claude plugin marketplace add billy-enrizky/openbrowser-ai
claude plugin install openbrowser@openbrowser-ai
```

## 8. Run examples

```bash
uv run examples/simple.py
```
