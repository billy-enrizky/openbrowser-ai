<Warning>
`on_step_start` and `on_step_end` are accepted by `Agent.run()` for compatibility, but they are not invoked in the default LangGraph execution path. Do not build required logic on them until the graph step node calls them.
</Warning>

## 1. Supported callbacks

Use these constructor callbacks instead:

| Callback | When it runs |
|---|---|
| `register_new_step_callback(browser_state, agent_output, step_number)` | After the model proposes actions and before those actions execute. It receives the pre-action browser state. |
| `register_done_callback(history)` | After a terminal run, with the final `AgentHistoryList`. |
| `register_should_stop_callback()` | Async callback that can request a cooperative stop. |
| `register_external_agent_status_raise_error_callback()` | Async callback for an external status error. |

`register_new_step_callback` and `register_done_callback` can be sync or async.

## 2. Example

```python
import asyncio

from openbrowser import Agent, ChatOpenAI


def on_new_step(browser_state, agent_output, step_number):
    print(f"Step {step_number} on {browser_state.url}")
    print(f"Proposed actions: {len(agent_output.action or [])}")


async def on_done(history):
    print("Final result:", history.final_result())


async def main():
    agent = Agent(
        task="Search for the latest news about AI",
        llm=ChatOpenAI(model="gpt-5-mini"),
        register_new_step_callback=on_new_step,
        register_done_callback=on_done,
    )
    await agent.run(max_steps=10)


if __name__ == "__main__":
    asyncio.run(main())
```

## 3. In-step actions

For logic that must run inside a step, use a custom tool instead of a hook. See [Add Tools](/customize/tools/add).

For lifecycle state, read `agent.status`. See [Agent Basics](/customize/agent/basics).

## 4. Why the old example changed

The previous page showed `await agent.run(on_step_start=..., on_step_end=...)`. Those arguments are still accepted, but the default graph does not call them. The callbacks above are the supported path today.
