### Navigation & Browser Control
- **`search`** - Agent-only browser navigation to DuckDuckGo, Google, or Bing. For CodeAgent and MCP, use the stateless `search_web` helper instead.
- **`navigate`** - Navigate to URLs
- **`go_back`** - Go back in browser history
- **`wait`** - Wait for specified seconds

### Page Interaction
- **`click`** - Click elements by their index
- **`click_xy`** - Click no-index canvas, PDF, embedded, or native-rendered targets using CSS viewport coordinates
- **`hover_xy`** - Move the pointer over no-index canvas, PDF, embedded, or native-rendered targets using CSS viewport coordinates
- **`input`** - Input text into form fields
- **`upload_file`** - Upload files to file inputs
- **`scroll`** - Scroll the page up/down
- **`scroll_xy`** - Wheel-scroll no-index surfaces using CSS viewport coordinates
- **`find_text`** - Scroll to specific text on page
- **`send_keys`** - Send special keys (Enter, Escape, etc.)

Prefer indexed actions whenever an element index exists. If converting screenshot coordinates, divide by `window.devicePixelRatio` before using an `*_xy` tool.

### JavaScript Execution
- **`evaluate`** - Execute custom JavaScript code on the page (for advanced interactions, shadow DOM, custom selectors, data extraction)

### Tab Management
- **`switch`** - Switch between browser tabs
- **`close`** - Close browser tabs

### Content Extraction
- **`extract`** - Extract data from webpages using LLM

### Visual Analysis
- **`screenshot`** - Request a screenshot in your next browser state for visual confirmation

### Form Controls
- **`dropdown_options`** - Get dropdown option values
- **`select_dropdown`** - Select dropdown options

### File Operations
- **`write_file`** - Write content to files
- **`read_file`** - Read file contents
- **`replace_file`** - Replace text in files

### Task Completion
- **`done`** - Complete the task (always available)

### CodeAgent and MCP execution helpers

The CodeAgent and MCP execution namespaces expose additional Python helpers beyond the Agent action registry:

- **`browser.get_browser_state_summary()`** - page metadata and interactive elements
- **`find_element(role=None, name=None, element_id=None, tag=None, *, timeout=0)`** - resolve an interactive index from a screenshotless state
- **`click_element(role=..., name=...)`** - find and click in one call
- **`fill_element(text, role=..., name=...)`** - find an input and type in one call
- **`get_tabs()`** - list tabs without reading the full DOM
- **`get_selector_from_index(index)`** - CSS selector for an element index
- **`download_file(url, filename=None)`** - download with browser cookies
- **`wait_for_download(timeout=30, url=None, lookback=0, download_ref=None)`** - wait for a terminal download phase; start it before the triggering click
- **`download_outcomes()` / `download_failures()`** - synchronous recent attempts and failures
- **`list_downloads()`** - list files in the downloads directory

Indexed actions use the latest browser state. Readiness failures are `element_index_missing`, `element_index_invalid`, `browser_state_not_ready`, and `element_index_stale`. Re-read browser state before retrying.

A registered action can still be unavailable. Action availability failures report `action_excluded`, `action_unknown`, `empty_domains`, `page_unknown`, or `domain_filtered`. `page_unknown` means the page URL is not known yet; `domain_filtered` means the action's domain filter does not include the current page. Check the registered action list and the page URL before retrying.
