To get started with OpenBrowser you need to install the package and set up an API key.

## 1. Installing OpenBrowser

<Tabs>
  <Tab title="Quick install">
    **macOS / Linux**

    ```bash
    curl -fsSL https://raw.githubusercontent.com/billy-enrizky/openbrowser-ai/main/install.sh | sh
    ```

    **Windows (PowerShell)**

    ```powershell
    irm https://raw.githubusercontent.com/billy-enrizky/openbrowser-ai/main/install.ps1 | iex
    ```

    Detects `uv`, `pipx`, or `pip` and installs OpenBrowser automatically.

    Install to `~/.local/bin` without sudo:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/billy-enrizky/openbrowser-ai/main/install.sh | sh -s -- --local
    ```
  </Tab>
  <Tab title="Homebrew">
    **macOS / Linux**

    ```bash
    brew tap billy-enrizky/openbrowser
    brew install openbrowser-ai
    ```

    Installs OpenBrowser into a Homebrew-managed virtualenv.
  </Tab>
  <Tab title="pip">
    ```bash
    pip install openbrowser-ai
    ```

    Agent and CodeAgent are included in the base package. Add optional providers:

    ```bash
    pip install "openbrowser-ai[all]"
    ```
  </Tab>
  <Tab title="uv (recommended)">
    Install the CLI globally:

    ```bash
    uv tool install openbrowser-ai
    ```

    Or create an isolated environment first:

    ```bash
    uv venv --python 3.12
    source .venv/bin/activate
    uv pip install openbrowser-ai
    ```

    Add optional providers with `"openbrowser-ai[all]"`.
  </Tab>
  <Tab title="uvx (zero install)">
    Run directly without installing -- `uvx` downloads and caches the package automatically:

    ```bash
    # MCP server mode
    uvx openbrowser-ai --mcp

    # CLI daemon mode
    uvx openbrowser-ai -c "await navigate('https://example.com')"
    ```

    No virtual environment needed. Ideal for Claude Code, Cursor, and other MCP clients.
    The default MCP transport is the lean stdio loop. Set `OPENBROWSER_MCP_TRANSPORT=sdk` to use the SDK transport. Invalid values exit with code 2.
  </Tab>
  <Tab title="pipx">
    ```bash
    pipx install openbrowser-ai
    ```

    Installs into an isolated environment with the `openbrowser-ai` command available globally.
  </Tab>
  <Tab title="From source">
    ```bash
    git clone https://github.com/billy-enrizky/openbrowser-ai.git
    cd openbrowser-ai
    uv venv --python 3.12
    source .venv/bin/activate
    uv pip install -e ".[all]"
    ```
  </Tab>
</Tabs>

<Info>
**No separate browser install needed.** OpenBrowser auto-detects any installed Chromium-based browser (Chrome, Edge, Brave, Chromium) and uses it directly. If none is found and `uvx` is available, Chromium is installed automatically on first run. To pre-install manually (requires `uvx`): `openbrowser-ai install`
</Info>

## 2. Try it without an LLM

Search and scrape work immediately. Neither command needs an API key.

```bash
# Search with the package-native DDGS client. This does not start a browser.
openbrowser-ai search "OpenBrowser MCP docs" --max-results 5

# OpenBrowser no-browser mode: no Chrome, Blink, or V8 process.
openbrowser-ai scrape https://example.com --no-browser --format markdown

# Batch scrape static pages with bounded concurrency.
openbrowser-ai scrape https://a.example https://b.example --no-browser --jsonl --concurrency 8
```

Search snippets are not evidence. Scrape and read the source page before you cite it.

`--no-browser` starts no Chrome, Blink, or V8 process, never falls back to a browser, and cannot run JavaScript, take screenshots, or use browser cookies. The asset flags `--no-css`, `--no-images`, `--no-fonts`, `--no-media`, and `--render-mode` control the browser fallback, not the no-browser HTTP path. Use the default `auto` engine when a page may need JavaScript.

## 3. Choose your favorite LLM
Create a `.env` file and add your API key.

```bash .env
touch .env
```

<Info>On Windows, use `echo. > .env`</Info>

Then add your API key to the file.

<CodeGroup>
```bash Google
# add your key to .env file
GOOGLE_API_KEY=
# Get your free Gemini API key from https://aistudio.google.com/app/u/1/apikey
```
```bash OpenAI
# add your key to .env file
OPENAI_API_KEY=
```
```bash Anthropic
# add your key to .env file
ANTHROPIC_API_KEY=
```
</CodeGroup>

See [Supported Models](/supported-models) for more.

## 4. Run your first agent

<CodeGroup>
```python Google
from openbrowser import Agent, ChatGoogle
from dotenv import load_dotenv
import asyncio

load_dotenv()

async def main():
    llm = ChatGoogle(model="gemini-flash-latest")
    task = "Find the number 1 post on Show HN"
    agent = Agent(task=task, llm=llm)
    await agent.run()

if __name__ == "__main__":
    asyncio.run(main())
```
```python OpenAI
from openbrowser import Agent, ChatOpenAI
from dotenv import load_dotenv
import asyncio

load_dotenv()

async def main():
    llm = ChatOpenAI(model="gpt-4.1-mini")
    task = "Find the number 1 post on Show HN"
    agent = Agent(task=task, llm=llm)
    await agent.run()

if __name__ == "__main__":
    asyncio.run(main())
```
```python Anthropic
from openbrowser import Agent, ChatAnthropic
from dotenv import load_dotenv
import asyncio

load_dotenv()

async def main():
    llm = ChatAnthropic(model='claude-sonnet-4-0', temperature=0.0)
    task = "Find the number 1 post on Show HN"
    agent = Agent(task=task, llm=llm)
    await agent.run()

if __name__ == "__main__":
    asyncio.run(main())
```
</CodeGroup>

## 5. Set up for your coding agent

The `setup` skill installs the CLI and Chromium, configures MCP and profiles, installs the plugin skills, and verifies a real browser session.

```bash
npx skills add billy-enrizky/openbrowser-ai --skill setup -a codex
npx skills add billy-enrizky/openbrowser-ai -a codex
```

These commands install skill files. They do not run the setup workflow. Invoke the `setup` skill after installation to install the CLI and Chromium, configure MCP, and verify a real browser session.

Replace `codex` with `claude-code`, `opencode`, or another supported agent name. The first command installs only the setup skill. The second installs all eight OpenBrowser skills. Claude Code can also use the plugin marketplace:

```bash
claude plugin marketplace add billy-enrizky/openbrowser-ai
claude plugin install openbrowser@openbrowser-ai
```

The portable MCP server command is:

```bash
uvx openbrowser-ai --mcp
```

Modern `2026-07-28` clients see seven tools: `create_context`, `execute_code`, `get_status`, `reset_browser`, `close_context`, `search_web`, and `scrape_web`. The legacy handshakes `2024-11-05`, `2025-03-26`, `2025-06-18`, and `2025-11-25` see four tools: `execute_code`, `get_status`, `reset_browser`, and `search_web`. `scrape_web` is stateless and uses OpenBrowser no-browser mode: it starts no Chrome, Blink, or V8 process and cannot run JavaScript, take screenshots, or use browser cookies.

This uses the lean stdio transport by default. Set `OPENBROWSER_MCP_TRANSPORT=sdk` to opt into the MCP SDK transport. Invalid values exit with code 2.
