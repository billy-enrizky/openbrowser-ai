## 1. Historical notice

Historical benchmark, not a current-version ranking. No universal winner is claimed.

The retired run does not record the CLI tool versions or a random seed. Those omissions remain part of its provenance limits.

This page previously contained the 2026-03-15 four-way CLI benchmark and the 2026-02-21 MCP server comparison. Those result tables and charts are retired as old-version evidence. The current native lanes measure different workloads and metrics, so they do not replace the model-driven CLI token, cost, or Agent and CodeAgent results. Those metrics remain unmeasured in the current lanes.

The retired paths, SHA256 digests, and sizes are recorded in [RETIRED_RESULTS.md](https://github.com/billy-enrizky/openbrowser-ai/blob/main/benchmarks/RETIRED_RESULTS.md). The files remain available in git history before this cleanup commit.
